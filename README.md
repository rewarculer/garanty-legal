# garanty-legal

Privacy Policy and Terms of Service for the **Garanty** Android app (`com.rewar.garanty`), served by GitHub Pages.

- [Privacy Policy](https://rewarculer.github.io/garanty-legal/privacy.html)
- [Terms of Service](https://rewarculer.github.io/garanty-legal/terms.html)

These files are generated from the `legal/` folder of the Garanty app repository, which is the source of truth. Edit them there and copy the result here, so a change to the subscription wording travels with the commit that changes the behaviour.
